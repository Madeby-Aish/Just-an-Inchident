# Just-an-Inchident — Formula 1 Race Strategist Chatbot

An interactive AI pit-wall race strategist built using **Python**, **Gradio**, and the **Groq API** (`openai/gpt-oss-120b`). Designed to break down Formula 1 race strategy, tire compound choices, undercut/overcut windows, Safety Car reactions, and FIA sporting regulations in real time.
